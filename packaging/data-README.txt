Build Doctor keeps its data in this folder: Path of Building, which it
installs on first start (about 390 MB, every file checked).

To move Build Doctor, move the whole Build Doctor folder. To remove it,
delete the folder. If you saved an API key for the AI coach, remove it
first with "Remove key" on the Ask the coach page: the key is kept in
Windows Credential Manager, not here.

Put the folder somewhere you can write to (Documents, Desktop, a games
drive), not in Program Files.
